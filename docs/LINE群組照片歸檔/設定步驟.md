# LINE 官方帳號 · 群組／私訊照片自動歸檔

**群組**或**私訊官方帳號**傳照片時，工具箱 API 透過 Webhook 下載到電腦並分資料夾存放。

---

## 多個官方帳號

LINE **每個官方帳號**在 Developers 都是獨立 Channel（各有一組 Token + Secret）。  
先前 `config.json` 只設一組，且 Webhook 只驗一個 Secret，所以**只有那一個帳號**的照片會歸檔。

現在可在 `lineAccounts` 加第二、第三個帳號；**Webhook 網址可相同**（都填 `https://你的API/line/webhook`），伺服器會依簽章判斷是哪個帳號。

```json
"lineChannelAccessToken": "第一個帳號 Token",
"lineChannelSecret": "第一個帳號 Secret",
"lineAccounts": [
  {
    "name": "包租官方帳號",
    "channelAccessToken": "第二個帳號 Token",
    "channelSecret": "第二個帳號 Secret"
  }
]
```

多帳號時照片會分開存：

```
LINE照片歸檔\
  星鴻官方帳號\
  包租官方帳號\
```

也可在單一帳號加 `"archiveDir": "D:\\專用路徑"` 自訂資料夾。

---

## 一、LINE 官方帳號（沿用現有即可）

你們 `server/config.json` 已有：

- `lineChannelAccessToken`
- `lineChannelSecret`

在 [LINE Developers Console](https://developers.line.biz/) 確認：

1. **Messaging API** → Webhook：**啟用**
2. Webhook URL：`https://你的API網址/line/webhook`（與照會通知相同）
3. **Allow bot to join group chats**（允許加入群組）：**開啟**
4. 官方帳號後台 → 設定 → **回應設定**：可關閉自動回覆（本功能預設**不回覆**群內訊息）

---

## 二、使用方式

### 群組

1. 將**官方帳號**邀進 LINE 群
2. 群內傳照片 → 自動歸檔

### 私訊

1. 使用者加官方帳號為好友後，**直接私訊傳照片**
2. 同樣會歸檔（不需拉進群）

公司電腦須執行 **`server\啟動公司主機.bat`**（需要時再開 **`server\啟動星鴻雲端隧道.bat`**），並保持服務運作。

---

## 三、歸檔路徑（預設）

未另外設定時，照片存到：

```
桌面\LINE照片歸檔\
  2026-07-03\
    群組名稱\                    ← 群組訊息
      20260703-151230_王小明_325708.jpg
    私訊_李小華\                 ← 私訊官方帳號
      20260703-152045_李小華_325709.jpg
```

同目錄有 `_archive-log.jsonl` 記錄每張照片的群組、傳送者、檔案路徑。

若要改路徑，在 `server/config.json` 設定：

```json
"lineGroupPhotoArchiveDir": "D:\\公司照片\\LINE歸檔"
```

---

## 四、config.json 選項

| 欄位 | 說明 |
|------|------|
| `lineGroupPhotoArchiveEnabled` | `true`（預設）開啟；`false` 關閉 |
| `lineGroupPhotoArchiveDmEnabled` | `true`（預設）也歸檔私訊照片；`false` 只處理群組 |
| `lineGroupPhotoArchiveDir` | 自訂資料夾；空白＝桌面 `LINE照片歸檔` |
| `lineGroupPhotoArchiveGroupIds` | 只歸檔指定群（陣列）；`[]`＝所有有官方帳號的群 |
| `lineGroupPhotoArchiveReply` | `true` 時群內回覆「已歸檔 N 張」；預設 `false` 靜默 |

---

## 五、測試

1. 重啟 API 主機
2. **私訊**或**群內**傳一張照片
3. 到 `桌面\LINE照片歸檔\今天日期\` 確認檔案
4. API 主機視窗應出現：`[line/archive] saved 1 → ...`

登入工具箱後可查：`GET /api/line/archive/status`（需 Bearer Token）

---

## 六、注意事項

- **API 主機須常開**；電腦關機或隧道斷線時無法收 Webhook
- 僅處理 **image / 多張圖（imageSet）**；檔案、影片、貼圖暫不歸檔
- LINE 內容下載有時效，請盡快由 Webhook 處理（正常在數秒內完成）
- 與照會推播共用同一官方帳號與 Webhook，互不衝突

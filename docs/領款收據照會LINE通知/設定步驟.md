# 領款收據主管照會 · 方案 A（Google 表單 + LINE Notify · 照會群）

業務填表 → **照會群** 收到「待照會」→ 主管照會完填回報 → **照會群** 收到「已照會」（可再加業務個人 Notify）。

預估設定時間：約 20～30 分鐘。  
**你需要準備什麼？** 見同資料夾 `你需要提供什麼.md`。

---

## 一、準備 LINE 照會群 + 群組 Notify Token（必做）

1. 建立 LINE 群組（例：`星鴻-領款收據照會`），拉入主管與需知會的業務。
2. 打開 https://notify-bot.line.me/ 登入。
3. 點 **發行權杖** → 選 **「透過群組接收 LINE Notify 的通知」**。
4. 選剛才的 **照會群** → 發行 → 複製 **Token**（只顯示一次）。
5. 貼到下列擇一處即可：
   - **推薦** Apps Script → 專案設定 → 指令碼內容 → `NOTIFY_GROUP_TOKEN` = 你的 Token
   - 或試算表「設定」列：角色 `照會群`、姓名 `領款收據照會群`、Token 欄貼上

> 不必把 Token 傳給他人；自己貼在 Google 專案內即可。

### 選用：照會完畢再通知業務個人

業務到 notify-bot 申請 **1 對 1** Token，試算表「設定」加列：角色 `業務`、姓名與表單下拉選單相同。  
若只用照會群、不設業務列，完畢通知也會出現在群裡（預設已開啟）。

---

## 二、建立試算表與三個工作表

1. Google 雲端硬碟 → 新增 **Google 試算表**，命名例：`星鴻_領款收據照會LINE`.
2. 建立三個工作表（分頁）並命名：
   - `設定`
   - `送件`
   - `完畢`
3. 試算表 → **擴充功能** → **Apps Script**。
4. 刪除預設程式碼，貼上本資料夾 `AppsScript-完整程式碼.gs` 全部內容 → **儲存**。
5. 在 Apps Script 編輯器執行一次 `setupSpreadsheetHeaders`（選函式 → 執行 → 首次需授權 Google 帳號）。

### 「設定」工作表範例（照會群版，最簡）

| 角色 | 姓名 | LINE_NOTIFY_TOKEN | 備註 |
|------|------|-------------------|------|
| 照會群 | 領款收據照會群 | （群組 Token） | 送件、完畢都會發到此群 |

加選個人通知時再加：

| 角色 | 姓名 | LINE_NOTIFY_TOKEN |
|------|------|-------------------|
| 業務 | 張三 | （張三 1對1 Token） |

- **角色** 可用：`照會群`、`業務`；舊版 `主管` 個人 token 仍會一併發送（可保留過渡）。
- **業務姓名** 需與表單下拉選單完全一致。

---

## 三、建立表單 1：業務送件（待照會）

1. 試算表 → **表單** → 建立新表單，或從 [Google 表單](https://forms.google.com) 建立。
2. 設定 → 回應 → **選擇目的地** → 連結到本試算表的 **`送件`** 工作表。
3. 建議欄位（標題請與下列一致，程式才能自動對應）：

| 題目類型 | 欄位標題 |
|----------|----------|
| 簡答 | 案件編號 |
| 下拉選單 | 業務姓名（選項＝設定表的業務姓名） |
| 下拉選單 | 區域（例：雙北、桃園、台中…） |
| 簡答 | 房東姓名 |
| 簡答 | 押金金額 |
| 段落 | 備註（選填） |

4. 複製表單連結給業務使用。

---

## 四、建立表單 2：主管照會完畢回報

1. 再建立一張表單，回應連到試算表 **`完畢`** 工作表。
2. 建議欄位：

| 題目類型 | 欄位標題 |
|----------|----------|
| 簡答 | 案件編號（**必須與送件表相同**） |
| 簡答 | 照會主管 |
| 下拉選單 | 照會結果（照會完畢 / 退回補件） |
| 段落 | 照會備註 |

3. 複製表單連結給主管（可放在照會登記表 SOP 或書籤）。

---

## 五、設定觸發條件（重要）

在 **Apps Script** 左側 **觸發條件**（時鐘圖示）→ **新增觸發條件**：

| 項目 | 表單 1（送件） | 表單 2（完畢） |
|------|----------------|----------------|
| 執行函式 | `onReceiptSubmitForm` | `onReceiptDoneForm` |
| 事件來源 | 試算表 | 試算表 |
| 事件類型 | 表單送出時 | 表單送出時 |

兩個觸發條件都要建立。若只有一個表單，可只建一個；建議兩表單分開較清楚。

> 亦可：表單 → 設定 → 腳本（舊版）— 建議用觸發條件較穩定。

---

## 六、測試

1. 執行 `testNotifyGroup` → **照會群** 應出現測試訊息。
2. （選用）執行 `testNotifyBusiness` → 有設業務個人 token 才會收到。
3. 送一筆 **業務送件** → 照會群出現「待主管照會」。
4. 相同案號送 **照會完畢** → 照會群出現「照會結果通知」。

---

## 七、選用：腳本內容屬性（進階）

Apps Script → **專案設定** → **指令碼內容**：

| 鍵 | 說明 |
|----|------|
| `NOTIFY_GROUP_TOKEN` | **照會群** Notify Token（建議必填） |
| `ENDORSEMENT_FORM_URL` | 覆蓋預設照會登記表網址（預設 `https://reurl.cc/0aEyZ9`） |
| `DONE_NOTIFY_TO_GROUP` | 完畢是否發照會群，預設 true；設 `false` 則只發業務個人 |
| `FALLBACK_BUSINESS_NOTIFY_TOKEN` | 無業務 token 且關閉群組完畢通知時的備援 |

---

## 八、與現有 SOP 銜接

1. 業務：續轉包領款收據條件符合 → 填 **業務送件表單**。
2. 主管：收到 LINE → 電話照會房東 → 填《處長照會登記表》→ 填 **照會完畢回報表單**。
3. 業務：收到 LINE「照會完畢」→ 繼續收據／進件流程。

工具箱「包租領款收據」區塊已加上本流程表單連結欄位（請將表單網址貼入 `docs/領款收據照會LINE通知/表單網址.txt` 或告知管理員更新 index.html）。

## 常見問題

**Q：主管沒收到？**  
- 檢查設定表「角色」是否為 `主管`、Token 是否正確。  
- 觸發條件是否啟用、是否授權過。

**Q：業務沒收到完畢通知？**  
- 完畢表的「案件編號」是否與送件表完全一致。  
- 送件表的「業務姓名」是否在設定表有對應 Token。

**Q：想通知 LINE 群組？**  
- 發行 Token 時選「透過群組接收」，貼到 `NOTIFY_GROUP_TOKEN` 或「照會群」列即可（本版預設做法）。

# 領款收據照會 · LINE 官方帳號推播（取代已停用之 LINE Notify）

> **LINE Notify 已全面停用**，請勿再使用 notify-bot.line.me。  
> 本版使用你們工具箱既有的 **Messaging API**，將通知推到 **照會 LINE 群**。

---

## 你需要準備什麼

| 項目 | 說明 |
|------|------|
| LINE 官方帳號 | Developers Console 的 Channel Access Token、Channel Secret（`server/config.json` 多半已有） |
| 照會 LINE 群 | 拉入官方帳號為好友／成員（依帳號類型操作） |
| API 主機常開 | 執行 `server\啟動公司主機.bat`（雲端隧道另開 `server\啟動星鴻雲端隧道.bat`）；**Netlify 網站**須另設定 API 網址（見下方「Netlify」） |
| Webhook 網址 | 指向 `https://你的網址/line/webhook`（與現有星鴻 LINE 機器人相同） |

**不必再提供：** LINE Notify Token、Google 表單（改工具箱內一張表單即可）。

---

## 一、建立照會群並邀請官方帳號

1. 建立 LINE 群，例：`星鴻-領款收據照會`。
2. 將 **官方帳號** 邀進群（須能收群組訊息）。
3. 確認 Messaging API 的 Webhook 已啟用，且網址可連到你們 API 主機。

---

## 二、自動取得群組 ID（建議）

1. 啟動 API 主機（`server\啟動公司主機.bat`）。
2. 將官方帳號 **加入照會群** 當下，伺服器會把 `groupId` 寫入：  
   `server/data/receipt-endorsement-config.json`
3. 工具箱租管師專區表單上方應顯示 **「LINE 照會群已就緒」**。

若未自動寫入，可至 [LINE Developers](https://developers.line.biz/) 後台查 groupId，手動填入 `server/config.json`：

```json
"lineReceiptNotifyGroupId": "Cxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

---

## Netlify 工具箱連線 API（必讀）

Netlify **只放靜態網頁**，沒有 `/api`。若未設定 API 網址，表單會顯示「API 連線失敗」或 JSON 錯誤。

1. 公司電腦執行 **`server\啟動公司主機.bat`** 與 **`server\啟動星鴻雲端隧道.bat`**，在隧道視窗複製 `https://….trycloudflare.com`（每次重開隧道可能變網址）。
2. 擇一設定（設定後 **重新部署 Netlify**）：
   - **A（建議）** Netlify 後台 → Environment variables → `NB_TRACKER_API_URL` = 上述 https 網址（建置腳本會寫入 `api-base.json`）。
   - **B** 專案根目錄編輯 `api-base.json`：`"base": "https://….trycloudflare.com"`，再 push / 部署。
3. `server/config.json` 的 `corsOrigins` 須含 `https://imaginative-narwhal-b98c84.netlify.app`（或你的 Netlify 網址）。
4. LINE Webhook 仍須指向 **雲端 API** 的 `/line/webhook`，不是 Netlify 網址。

表單上方顯示 **LINE 照會群已就緒** 才算連線成功。

```json
{
  "lineChannelAccessToken": "（官方帳號 Token）",
  "lineChannelSecret": "（Channel Secret）",
  "lineReceiptNotifyGroupId": "（可選，進群自動寫入則免填）",
  "receiptEndorsementFormUrl": "https://reurl.cc/0aEyZ9",
  "publicUrl": "https://你的雲端或公司網址"
}
```

## 四、使用方式（一張表單 · 五欄位）

路徑：**租管師專區 → 包租領款收據 → LINE 照會通知**

**租管師送件（五欄）：** 租管師姓名、物件地址、房東姓名、房東電話、押金  

**主管照會完畢（四欄）：** 物件地址、照會主管、照會結果、送件租管師姓名  

1. **租管師送件** → 照會群「待主管照會」。
2. **主管**電話照會 → [處長照會登記表](https://reurl.cc/0aEyZ9)。
3. **主管照會完畢** → 以**物件地址＋送件租管師姓名**對應送件紀錄 → 照會群「照會結果通知」。

紀錄存於 `server/data/receipt-endorsement.json`。

## 五、測試

1. 瀏覽器開 `http://127.0.0.1:8765/index.html`（或雲端網址），進租管師專區表單區。
2. 狀態列為 **LINE 照會群已就緒**。
3. 送一筆測試「業務送件」→ 照會群應有訊息。
4. 同案號送「主管照會完畢」→ 照會群應有完畢訊息。

API 自測：`GET /api/receipt-endorsement/status`  
應回 `{ "ready": true, ... }`

## 六、常見問題

**Q：顯示「需連線 API 主機」**  
- 勿用雙擊本機 `index.html`（file://）；請用 bat 啟動後的 http 網址。  
- Netlify 靜態站須在 `nb-api-config.js` 填公司 API 網址。

**Q：推播失敗 HTTP 403**  
- Token 過期或官方帳號不在群內。  
- groupId 錯誤：刪除 `receipt-endorsement-config.json` 後重新邀機器人進群。

**Q：還想用 Google 表單？**  
- 可保留試算表紀錄，但 **無法再用 Notify 發 LINE**；須改呼叫 `POST /api/receipt-endorsement`（進階，可再擴充）。

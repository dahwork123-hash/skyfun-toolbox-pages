# 領款收據照會 · LINE Notify「照會群」版 — 你需要提供什麼

採 **最少改動**：維持 Google 表單 + Apps Script，通知改發到 **LINE 群組**（一組群組 Token 即可）。

---

## 一、你一定要準備的（自己設定，不必把 Token 貼給外人）

### 1. LINE 照會群 + 群組 Notify Token（最重要）

1. 先建立 LINE 群組，例如：`星鴻-領款收據照會`  
   - 請把 **會照會的主管**、**需要被通知的業務／窗口** 都拉進群（依公司規定）。
2. 用 **你的 LINE** 打開 https://notify-bot.line.me/ 登入。
3. 點 **發行權杖** → 選 **「透過群組接收 LINE Notify 的通知」**。
4. 選剛建立的 **照會群** → 發行 → **複製 Token**（只顯示一次，請存記事本）。

> 此 Token 貼在試算表「設定」或 Apps Script 專案設定即可，**不必傳到聊天室或 email**。

### 2. Google 試算表（你可自建，或把編輯權限給設定的人）

- 試算表名稱（自訂即可）
- 三個工作表：`設定`、`送件`、`完畢`
- Apps Script 已貼上 `AppsScript-完整程式碼.gs`（群組版）

### 3. 兩張 Google 表單網址（建立後複製）

| 表單 | 用途 | 回應寫入工作表 |
|------|------|----------------|
| 業務送件 | 業務填案號、區域、押金… | `送件` |
| 主管照會完畢 | 主管填完照會結果 | `完畢` |

表單欄位標題請依 `設定步驟.md`，程式才對得到。

## 三、照會完畢要通知誰？（二選一，設定時決定）

### 做法甲（最省事，推薦）

- **送件、完畢都只發「照會群」**  
- 業務自己也會在群裡看到「已照會完畢」  
- 設定表只要 **一列**：

| 角色 | 姓名 | LINE_NOTIFY_TOKEN |
|------|------|-------------------|
| 照會群 | 領款收據照會群 | （群組 Token） |

### 做法乙（完畢再私訊業務）

- 送件 → 照會群  
- 完畢 → **照會群 + 該業務個人 Notify Token**（業務各自到 notify-bot 申請 1 對 1 Token）  
- 設定表多加「業務」列，姓名與表單下拉選單一致。

## 四、在 Apps Script 貼群組 Token（二選一）

**方式 1（推薦）— 專案設定，不用改試算表**

1. Apps Script → ⚙ **專案設定** → **指令碼內容** → 新增  
2. 內容：

| 屬性 | 值 |
|------|-----|
| `NOTIFY_GROUP_TOKEN` | 你的群組 Token |

**方式 2 — 試算表「設定」**

| 角色 | 姓名 | LINE_NOTIFY_TOKEN |
|------|------|-------------------|
| 照會群 | 領款收據照會群 | 群組 Token |

## 五、設定完成後請自測

1. 執行 `testNotifyGroup` → 照會群應出現測試訊息。  
2. 送一筆業務送件測試 → 群裡應有「待主管照會」。  
3. 用**相同案號**送照會完畢 → 群裡應有「照會結果通知」。

## 七、常見問題

**Q：一定要拉群嗎？**  
是。群組 Token 必須對應已存在的 LINE 群，且發行 Token 時要選該群。

**Q：群裡沒跳出通知？**  
- 群組是否允許 Notify（發行時有勾選該群）  
- Token 是否貼在 `NOTIFY_GROUP_TOKEN` 或「照會群」列  
- Apps Script 觸發條件是否已建立、表單是否連到正確工作表  

**Q：Notify 服務結束怎麼辦？**  
屆時再改官方帳號機器人 Push；表單與試算表可沿用。
